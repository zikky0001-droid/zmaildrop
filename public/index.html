04 / FAQ

Real questions, honest answers.

Is ZMAIL Drop really free?+

Yes — completely free with no paywall, no premium tier and no message limit hidden behind a subscription. It is a personal project maintained by Dev Zikky.

Do I need an account or password?+

No account, no password, no verification. You type a mailbox name and your inbox opens instantly. That is the convenience — but it is also why the mailbox is public, not private.

Are these inboxes private?+

No. Treat a temporary mailbox as public. Someone who knows the address may be able to access the same inbox.

Who can read my messages?+

Anyone who knows — or guesses — your mailbox name. Pick something unusual if you want a little extra obscurity, but never treat the inbox as secure storage.

How long does an inbox last?+

Temporary storage is not permanent. Inboxes can be cleared when they become inactive, including when an inbox does not receive a message within the service's inactivity window. Do not rely on it as long-term storage.

Do messages delete themselves?+

Yes. Messages and inactive inboxes are cleaned up automatically over time. If a message contains anything sensitive, delete it yourself as soon as you are done with it.

Can I send email from ZMAIL Drop?+

No. ZMAIL Drop is receive-and-read only. If you need to send emails from your app or website, use ZMAIL Zone (zmail.zone.id) — my email service with a sending API.

What can I safely use it for?+

Low-risk things: signing up for newsletters or trials, receiving one-time verification codes, grabbing gated downloads, testing email flows as a developer, or keeping spam away from your real address.

What should I never use it for?+

Anything that matters: banking, government services, your main social accounts, work accounts, password recovery for important logins, or any message you would not want a stranger to read.

My verification email isn't showing up — why?+

First, check the mailbox name for typos. Then refresh the inbox and wait 1–2 minutes — senders can be slow. Also note: some websites block temporary-email domains entirely. If nothing arrives after several minutes, that sender probably refuses temp-mail addresses.

Can I use the same mailbox again later?+

Yes, as long as the inbox still exists. Revisit the same address and your messages will be there — but remember, anyone else can revisit it too.

Does it work on my phone?+

Yes. ZMAIL Drop runs in any modern browser on phones, tablets and desktops. No app to install, nothing to download.

Is there an API for developers?+

ZMAIL Drop itself is a simple web inbox. For programmatic email — sending messages from your own app — use ZMAIL Zone at zmail.zone.id, which is built around an email-sending API.

What happens to my data?+

Messages live in temporary storage and are removed automatically after 24 hours or when you delete them. There is no account profile and nothing permanent tied to you — which is exactly the point.

Who built ZMAIL Drop, and why?+

ZMAIL Drop is a personal project by Dev Zikky — built as a free, no-frills temporary mailbox anyone can use. You can read more about the developer and his other projects on the Developer page.
