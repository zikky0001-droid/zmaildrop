ZMAIL Drop Public API

Query temporary inboxes, read messages, and delete them — from your apps, bots, or scripts. No signup, no API key, no cost. Rate limit: 30 requests/minute per IP.

Browse endpoints ↓ Quick start
QUICK START

One curl. That's it.

# List all messages in mailbox "2" curl -s "https://zmaildrop.vercel.app/api/v1/inbox?mailbox=2"
ENDPOINTS

Everything the API does.

GET/api/v1/health

Status check. Confirms the service is online and whether Firebase is connected.

curl -s "https://zmaildrop.vercel.app/api/v1/health"
GET/api/v1/domains

Lists the domains this API can receive mail on.

curl -s "https://zmaildrop.vercel.app/api/v1/domains"
GET/api/v1/inbox?mailbox=:name

Lists all messages in a mailbox. Results are cached for 3 seconds to protect the upstream.

curl -s "https://zmaildrop.vercel.app/api/v1/inbox?mailbox=2"
GET/api/v1/message?mailbox=:name&id=:id

Reads a single message by ID, including the raw MIME data field for attachment parsing.

curl -s "https://zmaildrop.vercel.app/api/v1/message?mailbox=2&id=rvRN00Odx3"
DELETE/api/v1/message?mailbox=:name&id=:id

Permanently removes a message from the mailbox.

curl -s -X DELETE "https://zmaildrop.vercel.app/api/v1/message?mailbox=2&id=rvRN00Odx3"

JavaScript & Python.

const res = await fetch("https://zmaildrop.vercel.app/api/v1/inbox?mailbox=2"); const json = await res.json(); if (json.ok) { for (const msg of json.data.messages) { console.log(msg.subject, msg.headerfrom); } }
import requests r = requests.get("https://zmaildrop.vercel.app/api/v1/inbox?mailbox=2") data = r.json() if data["ok"]: for msg in data["data"]["messages"]: print(msg["subject"], "-", msg["headerfrom"])
LIMITS & HEADERS

Fair use, clearly stated.

30 requests / minute per IP. Exceeding this blacklists your IP for 5 minutes. Every response includes standard rate-limit headers:

X-RateLimit-Limit: 30 X-RateLimit-Remaining: 14 X-RateLimit-Reset: 1758550830 # unix seconds Retry-After: 43 # only on 429
ERROR CODES

What can go wrong.

INVALID_MAILBOX 400 Mailbox name failed validation INVALID_ID 400 Message ID failed validation MESSAGE_NOT_FOUND 404 Message doesn't exist or expired RATE_LIMITED 429 You've hit 30 req/min IP_BLACKLISTED 429 Your IP is temporarily blocked METHOD_NOT_ALLOWED 405 Wrong HTTP verb for this endpoint UPSTREAM_BUSY 503 Server queued too many requests at once UPSTREAM_ERROR 502 Maildrop itself failed
